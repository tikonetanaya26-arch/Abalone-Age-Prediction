# Abalone-Age-Prediction
Abalone age prediction using python , Data Analysis and Linear Regression

Project Overview

This project uses Python and Machine Learning to predict the age of abalones using their physical measurements.

Objective

To build a Linear Regression model that predicts abalone age based on features such as length, diameter, height and weight.

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Dataset

The Abalone dataset contains 4,177 records and 9 columns. The Rings column is used to estimate the age of abalones.

Steps Performed

1. Loaded and explored the dataset.
2. Checked missing values.
3. Performed data visualization.
4. Created a correlation heatmap.
5. Converted categorical data into numerical values.
6. Separated features and target variables.
7. Split data into training and testing sets.
8. Trained a Linear Regression model.
9. Generated predictions.
10. Evaluated model performance.

Project Files

- "Abalone_Age_Prediction.ipynb" – Google Colab notebook.
- "Abalone_Age_Predictions.csv" – Actual and predicted results.

Conclusion

This project helped me understand data preprocessing, data visualization, regression and model evaluation using Python and Machine Learning.
